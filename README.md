# ERP---System
ERP «Энерготех» (рабочее название Монолит) — система управленческого учёта для строительной компании. В ней ведутся: объекты и работы; бюджет, расходы, сравнение плана и факта; закупки: заявки, согласование, приёмка поставок; склад: остатки, приход, выдача, списание; договоры, контрагенты; пользователи и права по ролям и объекта.
