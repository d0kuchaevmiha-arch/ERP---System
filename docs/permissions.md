# Доступ

Сессия: подписанная HTTP-only cookie SameSite=Lax, Secure в production; пароль scrypt с индивидуальной солью. Origin проверяется для POST. 10 неудачных попыток входа на IP за 15 минут блокируются в памяти процесса.

Роли текущей реализации: `super_admin`, `director`, `project_manager`, `construction_manager`, `foreman`, `procurement_manager`, `warehouse_manager`, `finance_manager`, `accountant`, `read_only`. Директор и администратор могут изменять объекты организации; другие роли записи должны иметь `project_access.permission=edit` на объект. `read_only` не может создавать записи. Согласование/приемка дополнительно доступны только директору, администратору, руководителю проекта и снабжению.

Ограничения: гранулярные permissions, department ACL, безопасные фильтры для всех чтений и делегирование еще не реализованы; не использовать текущий API для нескольких независимых организаций. ERP_PRIVATE_MODE=true обязателен для непубличной установки. Для интернета необходим внешний rate-limit и централизованное хранение счетчиков.
