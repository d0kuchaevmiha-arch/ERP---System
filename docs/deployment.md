# Развертывание

Для локального демо: `cp .env.example .env`, задайте секреты, `docker compose up --build`. Контейнеры: PostgreSQL 16 с постоянным volume и приложение Next.js 16 на порту 3000. Healthcheck `/api/health`.

**Не публикуйте эту конфигурацию как production без доработок.** Требуются HTTPS reverse proxy (например, Nginx), ERP_PRIVATE_MODE=true, секреты вне репозитория, запрет прямого доступа к БД, управляемые миграции вместо `drizzle-kit push` при старте, сетевые ограничения, централизованные логи, резервное копирование и восстановление, ротация паролей, автоматические тесты и закрытие API-тенантной утечки. Изменения схемы перед production должны проходить ревью и миграции.
