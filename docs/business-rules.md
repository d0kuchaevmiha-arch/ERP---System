# Бизнес-правила

- Бюджет = сумма budget_lines по объекту. Факт = сумма expenses. Отклонение в панели = бюджет минус прогноз. При новом расходе, когда накопленный факт превысил бюджет, сервер создает уведомление.
- Остаток = сумма приходов и возвратов минус сумма выдач и списаний. Если запрошенная выдача больше остатка, транзакция откатывается с понятной ошибкой. При новом движении ниже min_stock создается уведомление.
- Приемка доступна только для согласованного заказа; частичный приход не может превысить заказанное количество. Приемка, изменение receivedQuantity и аудит атомарны.
- Просрочка работы: endDate < сегодня и progress < 100. Просрочка поставки: dueAt < сегодня и receivedQuantity < quantity. Дефицит: balance < minStock.
- Деньги NUMERIC(18,2), количество NUMERIC(18,3); стоимость списания рассчитывается в целых копейках. Формальные счета, НДС и налоговые правила не моделируются.
